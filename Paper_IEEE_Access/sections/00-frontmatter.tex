\begin{abstract}
Bone X-ray lesion segmentation is a challenging task because lesions are often small, low-contrast, and visually entangled with the surrounding anatomy. In this setting, the main challenge typically lies in localizing the suspicious region rather than refining the lesion's boundary. A practical strategy is to narrow the search space before segmentation itself is performed. We realize this idea through a direct interactive approach: a clinician supplies a coarse bounding box, which the model then uses as a spatial guidance signal.

We propose PGA-UNet, a lightweight prompt-guided CNN that converts the bounding-box prompt into a Gaussian-smoothed plateau heatmap, modulates encoder features according to the prompt through a Prompt Spatial Gate (PSG), and sustains prompt influence in the decoder through a Conditional Attention Decoder (CAD). The goal is not only to use the prompt to indicate where segmentation should occur, but also to keep small-lesion-relevant features active throughout the network.

Attention U-Net serves as the automatic baseline for prompt-free segmentation, while SAM-Med2D provides a prompt-matched reference. The main experiments evaluate PGA-UNet on BTXRD and FracAtlas at multiple resolutions under controlled covering and off-center boxes. Small-lesion and ablation analyses examine whether the proposed prompt-conditioned design remains useful when the target area is limited. Because all reported boxes are simulated around annotated lesions, these experiments assess prompted segmentation after controlled localization rather than unconstrained lesion detection or clinical usability.

Component-contribution analysis evaluates PSG, CAD, and Gaussian prompt encoding within the tested ablation configurations. The efficiency analysis measures parameter count, FLOPs, memory, and latency in the specified benchmark environment. The resulting evidence is interpreted within the controlled prompted-segmentation protocol and does not establish calibrated confidence, clinical robustness, patient-level generalization, or cross-dataset transfer. The quantitative tables in the current manuscript draft are being refreshed after retraining under the standardized 80/20 \texttt{center\_mixed} protocol and should be read accordingly.
\end{abstract}
