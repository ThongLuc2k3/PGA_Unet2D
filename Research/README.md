# PGA-UNet follow-up research

This branch (`research/prompt-scale-protocol`) is an independent research space, entirely separate from the paper currently being submitted on `main`. It exists to dig into three directions raised in advisor discussions, worked on one at a time in the priority order below.

1. **Prompt scale protocol** (`01_prompt_scale_protocol/`, decided): find a better way to construct the prompt box than the old independent-per-side random expansion. Decided: `center_zoom` scale x2 + `center_shift` ratio 0.3. Across the 6 trained (scale, shift) configurations, this gave the best Dice/CBL under both the Zoom and Zoom + shift test conditions (Zoom Dice 0.8700, Zoom + shift Dice 0.8195), so this is the box protocol carried into stages 2 and 3. Not yet repeated on FracAtlas.
2. **Loss function** (`02_loss_function/`, in progress): does the segmentation loss need changing to improve Dice/HD95/CBL, and if so, exactly where. The earlier centroid-alignment and recall-weighted Tversky attempts stay removed (the full test set showed no deficiency for either to fix), but a size-based breakdown of the small-lesion subset surfaced a narrower gap the aggregate hides: precision trails recall specifically on the 50 smallest-GT-area test images, i.e. over-segmentation on small lesions. Currently working on: a size-conditioned Tversky loss (`size_weighted_tversky_loss` in `train.py`, `USE_SIZE_TVERSKY=1`) that targets exactly this, alpha=beta=0.5 for large lesions (identical to Dice), alpha rising toward `SIZE_TVERSKY_ALPHA_MAX` for small ones. Not yet trained.
3. **Uncertainty/confidence** (`03_uncertainty_confidence/`, decided): how to know whether a prediction can be trusted with no ground truth at real inference time. Decided: `QualityHead`, a small head trained jointly with PGA-UNet (its loss is fully gradient-isolated, so it can never affect segmentation), over a hand-crafted-feature estimator, chosen because it stays in sync automatically every time PGA-UNet is retrained instead of needing a redo each time. Measured: `predicted_quality` reaches Spearman rho=0.493 (p=1.3e-15, N=232) against real Dice, versus rho=0.132 for the free CAD `prompt_confidence` gate, clearing the bar to keep `QualityHead` as primary. A future multi-prompt ranking/recommendation feature built on top of whichever confidence signal proves reliable belongs only in the interactive demo notebook (`Source/File_Test/btxrd/test-Demo_Interactive_PGA_Unet-btxrd.ipynb`), not in this research branch's train/test notebooks.

## Core principle: this is a sandbox, not a pipeline into the paper

`nothing here is merged back into the paper on main until it is validated`. This branch is a testing ground: numbers and conclusions only make it into the paper once real experiments here back them up. There is no pressure to match or follow whatever `main` is currently doing. The two are separate lines of work; `main` only receives results back after this branch has validated them.

Decisions here are evaluated purely on this branch's own internal logic: numbers actually measured, and the goals advisors set for it. `main` is not used as a reference or comparison point unless explicitly requested. This applies in particular to `main`'s own `zoom_out`/`shift`/`mixed` prompt protocol (an unrelated, incompatible box-construction method) and to `main`'s current training regime: neither should be treated as a target this branch needs to track.

## Training protocol: `center_mixed`, this branch's own decision

Every stage above was originally trained "zoom-only" (`TRAIN_PROMPT_MODE=center_zoom`; `center_shift` was evaluation-only). This branch now trains `center_mixed` instead: each training sample independently gets `center_zoom` or `center_shift` with 50/50 probability (`dataset.py`), so the model is not trained on a narrower prompt distribution than it is tested on. This was arrived at independently, on this branch's own reasoning, not by tracking `main`.

Consequence: stage 1's `center_zoom` x2/shift0.3 winner above was selected under zoom-only training, not yet reconfirmed under `center_mixed`. `train-integrated-center-mixed-x2-shift03-btxrd.ipynb` (this folder) trains one checkpoint combining all three decisions above (`center_mixed` x2/shift0.3, size-conditioned Tversky, QualityHead) and tests it on the full test set, the small-lesion subset, and the confidence-signal correlation, all in one run. Not yet run.

Numbers and code changes only land here once real experiments back them up. Illustrations that are conceptual mockups rather than model output are labeled as such in their own folder.
