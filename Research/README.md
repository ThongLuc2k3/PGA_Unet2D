# PGA-UNet follow-up research

This branch (`prompt-scale-protocol`) tracks the three follow-up research directions raised in advisor discussions, worked on one at a time in the priority order below. Each stage is trained and evaluated multiple times before moving to the next; nothing here is merged back into the paper on `main` until it is validated.

1. **`01_prompt_scale_protocol/`** (decided): replace the independent-per-side random box expansion with a box centered on the tight lesion box and scaled outward by a fixed multiplier. Across the 6 trained (scale, shift) configurations, `center_zoom` x2 with `shift_ratio=0.3` gave the best Dice/CBL under both the Zoom and Zoom + shift test conditions (Zoom Dice 0.8700, Zoom + shift Dice 0.8195), so this is the box protocol carried into stages 2 and 3. Still below the current paper's `zoom_out` protocol on raw Dice; not yet repeated on FracAtlas.
2. **`02_loss_function/`** (shelved, not current work): a centroid-alignment loss and a recall-weighted Tversky loss were implemented, then removed after checking them against the x2/shift0.3 numbers, precision/recall are already balanced and CBL is already 0.92-0.96, so neither had a real deficiency to fix. Documented as a checked-and-not-needed finding, not an oversight; revisit only if a future checkpoint shows the specific gap either one targets.
3. **`03_uncertainty_confidence/`** (current stage): a no-GT score for how much to trust a prediction. Decision: `QualityHead`, a small head trained jointly with PGA-UNet (its loss is fully gradient-isolated, so it can never affect segmentation), is the primary approach over a hand-crafted-feature estimator, chosen because it stays in sync automatically every time PGA-UNet is retrained instead of needing a redo each time. Train+test notebook (`train_quality_head_x2_shift03_btxrd.ipynb`) is written and ready; not yet run. A hand-crafted-feature estimator remains the documented fallback if `QualityHead`'s correlation with real Dice turns out weak. A future multi-prompt ranking/recommendation feature built on top of whichever confidence signal proves reliable belongs only in the interactive demo notebook (`Source/File_Test/btxrd/test-Demo_Interactive_PGA_Unet-btxrd.ipynb`), not in this research branch's train/test notebooks.

Numbers and code changes only land here once real experiments back them up. Illustrations that are conceptual mockups rather than model output are labeled as such in their own folder.
